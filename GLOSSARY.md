# Timer Toolbox

Timers a teacher puts up on the classroom screen so the whole class can see how much time is left. The first is the pie timer.

## Language

**Tool**:
One kind of timer in the toolbox, such as the pie timer.
_Avoid_: App, mode, widget

**Timer**:
A span of time the class watches count down, made of one or more segments in order; a teacher saves timers and runs them in a tool.
_Avoid_: Countdown, clock, alarm, preset

**Segment**:
One labeled chunk of a timer, such as "Warm-up" or "Clean up".
_Avoid_: Section, slice, chunk, block, phase

**Pie timer**:
A timer drawn as a circle split into its segments, showing both how much time is left and which segment the class is in.
_Avoid_: Time pie, donut timer, visual timer

**Advance**:
Moving from one segment to the next, either automatically or when the teacher taps.
_Avoid_: Transition, rotate, next

**Chime**:
The sound played when a timer advances to its next segment.
_Avoid_: Bell, alert, transition sound

**End sound**:
The sound played when a timer's last segment reaches zero.
_Avoid_: Alarm, bell, chime

**Overtime**:
The time that has passed since a timer reached zero, shown while the timer keeps counting up.
_Avoid_: Overrun, extra time

**Pop-out**:
A small window showing the timer that stays on top of whatever else is on the classroom screen.
_Avoid_: Overlay, floating timer, widget, mini-timer
